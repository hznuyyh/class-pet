# 班级宠物系统

一个免部署后端的班级宠物经营系统。纯原生 HTML/CSS/JavaScript，无构建步骤、无依赖安装，直接用浏览器打开 `index.html`，或启动任意静态文件服务即可使用。所有数据保存在浏览器本地，适合老师在教室电脑上单机使用。

## 功能总览

### 班级与学生

- 创建多个班级、手动添加学生、Excel 批量导入学生（学号、姓名、性别，支持 `.xlsx/.xls/.csv`），学号班内唯一
- 学生名单支持按学号/姓名实时检索
- 每个班级可一键生成演示数据

### 宠物养成

- 12 种普通宠物 + 4 种神兽，每名学生限养 1 只
- 新导入的学生自动获得一只随机普通宠物；每个学生有 1 次「抽取」机会：重新抽取（5% 概率神兽）或自选一只普通宠物
- 神兽可通过「神兽进化核心」（500 积分）随机进化获得
- 生活属性：健康、饱食、心情；战斗属性：力量、速度、体质、防御、会心（5 项）
- 属性加点为「临时拟加 + 手动确认」模式；「忘却卷轴」（10 积分）可洗点
- 宠物升级解锁高等级形象（每只宠物 8 段进化素材）；经验药水加速升级
- 商城：生活物资、装备（武器/护甲/饰品，每槽位各一件）、进化核心

### 积分与考试

- 考试成绩 Excel 导入（支持模板下载，模板自动预填班级名单）、逐个录入
- 每次录入保存为一条历史记录，可展开查看详情
- 成绩换积分：每 10 分换 1 积分，向下取整
- 老师手动加分/扣分并记录原因，全部积分变动有流水

### 对战

- 个人对战 PVP：双方各消耗 10 积分，胜者得 20 积分；回合制战斗播报 + 动态回放
- 技能系统：每只宠物专属技能，会心、追击（速度差越高追击概率越高）等机制

### 冠军赛（班级赛 / 天下第一武道大会）

- **班级赛**（每班独立）：全班分 4 组单循环，胜 1 分，每组前 4 名晋级；晋级边界积分并列自动加赛（积分列显示 `小组分+加赛分`）；淘汰赛为专业对阵树（带连接线），打完一轮自动生成下一轮
- **天下第一武道大会**（跨班）：至少选 2 个班级，每个班须先打完一届班级赛取前 16 名；选手随机混编 4 组（每组最多 8 人），每组前 4 名晋级，淘汰赛固定 16 强；赛事记录参赛班级，可在历届列表查看
- 同类赛事有进行中一届时不能新建（班级赛按班级判断，武道大会全局唯一）
- 比赛为满状态镜像对战：不消耗饱食/心情/积分
- 名次奖励分档设置（1/2/3/4 名单独，5-8、9-16、17+ 各一档，可为 0）
- **冠军称号**：夺冠获得专属称号道具（自定义，至少 2 字），进入背包，有效期 1 个月；可佩戴/卸下，同时只能佩戴一个；佩戴后全属性 +1；姓名展示为「姓名·宠物·称号」

### 排行榜与图鉴

- 排行榜按宠物等级或胜率，本班/全部班级两个口径；佩戴称号的学生展示称号
- 宠物图鉴：普通/神兽分区，等级进化形态悬停预览
- 物资图鉴、战斗记录流水

## 数据保存

- 每次操作自动写入浏览器 `localStorage`（只保留关键数据，完整战报自动归档到 IndexedDB）
- 滚动备份最近 3 份快照
- 可选「文件同步」：把数据同步保存到本地 JSON 文件（需 Chromium 内核浏览器），localStorage 清空时自动从文件恢复
- 顶部「备份」可导出完整 JSON；「恢复」可导入

## 如何运行

### 方式一：直接打开（最简单）

双击 `index.html` 即可在浏览器中使用。

> 注意：直接以 `file://` 打开时，Excel 导入、图片素材在部分浏览器（尤其 Safari）下可能受限，数据也仅保存在该浏览器 profile 中。推荐日常使用方式二。

### 方式二：本地静态服务（推荐）

任意一种即可：

```bash
# Python（Windows/macOS/Linux 自带或易装）
python -m http.server 8080

# Node.js
npx serve .
```

然后浏览器访问 `http://localhost:8080`。

### Windows 上完美运行

1. 用 Edge 或 Chrome（系统自带 Edge 即可），无需安装任何东西
2. 在项目文件夹地址栏输入 `cmd` 回车，执行 `python -m http.server 8080`（若无 Python，可下载安装，安装时勾选 Add to PATH；或改用 `npx serve .`）
3. 访问 `http://localhost:8080`
4. 数据保存在浏览器 localStorage 中——请固定使用同一个浏览器，不要用隐私/InPrivate 模式，否则数据不会保留
5. 强烈建议开启顶部「文件同步」，把数据落到本地 JSON 文件，防止浏览器清理数据后丢失；换电脑时可用「备份」导出 JSON、在另一台机器「恢复」导入
6. 若要彻底免装 Python/Node，也可把整个文件夹放到任意静态托管（如 GitHub Pages）上在线使用

## Excel 模板

班级页提供「下载导入模板」，表头建议：

| 学号 | 姓名 | 性别 | 初始积分 |
| --- | --- | --- | --- |
| 202601 | 张小满 | 女 | 0 |

「初始积分」可不填，仅新学生导入时生效。重复学号会更新姓名与性别，不会覆盖已有积分。成绩导入模板表头含「成绩/分数/得分/score」列即可匹配。
